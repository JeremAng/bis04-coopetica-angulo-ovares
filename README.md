# Descripción del sistema
Sistema de escritorio desarrollado en Java para centralizar la gestión de sucursales, asociados, aportes, cuentas y préstamos de CoopeTica R.L., conservando la información entre sesiones mediante archivos de texto y permitiendo generar reportes.

# Requisitos para ejecutarlo
- JDK: Java Development Kit (JDK) 25
- Entorno de desarrollo: Apache NetBeans

# Instrucciones de ejecución
1. Clonar el repositorio: `git clone <URL-del-repositorio>`
2. Abrir Apache NetBeans y seleccionar **File > Open Project...**
3. Seleccionar la carpeta del proyecto clonado y hacer clic en **Open Project**.
4. Presionar **F6** (o clic derecho sobre el proyecto > **Run**) para compilar y abrir la ventana principal.
